Building

  1. Install a Retribution loader with config support (any mentioned in Installing).
  2. Go to Settings > General and enable Developer Settings.
  3. Clone the repository 
    git clone https://github.com/Retribution-Mod/retribution-bundle.git
  4. Install dependencies 
    bun i
  5. Build Retribution's code 
    bun run build
  6. In the newly created dist directory, run a HTTP server. We recommend http-server.
  7. Go to Settings > Developer enabled earlier. Enable Load from custom URL and input the IP address and port of the server (e.g. http://192.168.1.236:4040/retribution.js) in the new input box labeled Retribution URL.
  8. Restart Discord. Upon reload, your device will download Retribution's bundled code from your server, rather than GitHub.
  9. Make your changes, rebuild, reload, go wild!

Alternatively, you can directly serve the bundled code by running bun serve. retribution.js will be served on your local address under the port 4040. You will then insert http://<local ip address>:4040/retribution.js as a custom URL and reload. Whenever you restart your mobile client, the script will rebuild the bundle as your client fetches it.

If the bundle keeps being cached and not updated, you can instead tap the Settings > Developer > Clear JS bundle option which will prompt you to reload.

Build targets

The classic bundle supports two build targets:

  • bun run build --target old — for Discord builds 340.x and below.
  • bun run build --target new — for Discord builds 341.x and above (RN 0.86+).
