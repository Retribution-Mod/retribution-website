Retribution

A client modification for Discord on Android and iOS. Run plugins, themes, and fonts — your app, your rules.

Download Read the docs

Open source. Free. Built on the Bunny loader stack.

What you get

Retribution extends Discord without replacing it. It runs inside the official app and gives you real control over the client.

Plugins

Install from a built-in browser or paste a URL. Vendetta, Revenge, and Bunny plugins work out of the box.

Themes

Recolor Discord with community themes or make your own. Full raw and semantic color support.

Fonts

Swap Discord's typeface with any Google Font, or install a custom font spec.

Open source

All source is public. The bundle, manager, loaders, and docs are on GitHub under the Retribution-Mod organization.

Developer tools

Built-in React DevTools, custom bundle URLs, eval console, and a recovery mode for when things go wrong.

Android + iOS

Install with the manager on Android, or use the Xposed module, sideload, jailbreak, or TrollStore on iOS.

Ready to start?

Pick your platform and grab the latest release. The install docs walk you through every step.
